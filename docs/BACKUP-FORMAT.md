# صيغة النسخة الاحتياطية للتصحيحات

> الإصدار الحالي للصيغة: **2** — كُتبت هذه الوثيقة في ١٢ ربيع الآخر ١٤٤٨هـ، وأُضيف إليها حقل `blocks` في ١٣ ربيع الآخر ١٤٤٨هـ (حقلٌ اختياري، فالرقم باقٍ)، وصار ملفا «تصدير المصدر» يحملان موقعهما في ١٤ ربيع الآخر ١٤٤٨هـ.

زرّ «تصدير تصحيحاتي» في صفحة الإعدادات يُنشئ ملف JSON فيه تصحيحاتك وقواعدك الذكية، وزرّ الاستيراد يقبله ويقبل صيغًا أقدم منه. هذه الوثيقة تصف الملف حقلًا حقلًا، ليُقرأ أو يُولَّد بأداةٍ أخرى دون تخمين.

## الملف لموقعٍ واحد

```json
{
  "_app": "claude-mutarjim",
  "_kind": "terms",
  "_version": 2,
  "lang": "ar",
  "domain": "support",
  "terms": [
    { "en": "Contact support", "ar": "تواصل مع الدعم" }
  ],
  "rules": [
    { "en": "Delete {count} chats?", "ar": "حذف {count} محادثة؟" }
  ],
  "blocks": {
    "3f9a0c2e7b1d4a58": "راجع <a1>أفضل الممارسات</a1> لضبط <c2/>."
  }
}
```

## الملف للمواقع كلها (عند اختيار «الكل» في رأس الصفحة)

```json
{
  "_app": "claude-mutarjim",
  "_kind": "terms",
  "_version": 2,
  "lang": "ar",
  "domains": {
    "app":  { "terms": [ … ], "rules": [ … ] },
    "docs": { "terms": [ … ], "rules": [ … ], "blocks": { … } }
  }
}
```

## ملفا «تصدير المصدر»

زرّا «تصدير المصدر بلا ترجمة» و«تصدير المصدر مترجَمًا» يُنشئان الصيغة نفسها بنوعٍ آخر (`_kind`: `source-bare` أو `source-full`)، ويحملان موقعهما كذلك: `domain` مع `count` و`terms` لموقعٍ واحد، أو `domains` لـ«المواقع كلها» وقيمة كلٍّ منها `{count, terms}` بقاموس ذلك الموقع. وفي `source-bare` حقل `ar` فارغٌ في كل سطر. فإذا ملأتَ الترجمات واستوردت الملف عاد كلُّ قسمٍ إلى موقعه.

```json
{
  "_app": "claude-mutarjim",
  "_kind": "source-full",
  "_version": 2,
  "lang": "ar",
  "domain": "docs",
  "count": 1042,
  "terms": [ { "en": "Intro to Claude", "ar": "مقدمة عن Claude" } ]
}
```

## الحقول

| الحقل | معناه |
|---|---|
| `_app` | ثابت: `claude-mutarjim`. يميّز ملفات الإضافة عن غيرها. |
| `_kind` | `terms` للتصحيحات، و`source-bare` أو `source-full` لملفي «تصدير المصدر». |
| `_version` | رقم الصيغة. يزيد متى تغيّر معنى حقلٍ قائم، ولا يزيد لحقلٍ جديدٍ اختياري. |
| `lang` | لغة الترجمة (`ar`). |
| `domain` | الموقع الذي تخصّه التصحيحات في ملف الموقع الواحد. |
| `domains` | في الملف الشامل: كائنٌ مفاتيحه أسماء المواقع، وقيمة كلٍّ منها `{terms, rules, blocks}` (أو `{count, terms}` في ملفي المصدر). |
| `count` | في ملفي المصدر: عدد أسطر `terms`. |
| `terms` | مصفوفة `{en, ar}`: النص الإنجليزي كما يظهر في الصفحة، وترجمتك له. |
| `rules` | مصفوفة `{en, ar}` للقواعد الذكية: نصٌّ فيه متغيّرات بين قوسين معقوفين مثل `{count}`، والترجمة تستعمل الأسماء نفسها. |
| `blocks` | (اختياري) تصحيحات فقرات المقالات في المواقع ذات المتون (`support` و`privacy` و`docs`): كائنٌ مفتاحه **بصمة الفقرة** (16 خانةً ست عشرية من تطبيع نصّها الإنجليزي — `blockFp` في `cml-shared.js`) وقيمته **قالبها العربي**: الترجمة بعناصرها النائبة كما في الأصل وبترتيبه — `<aN>…</aN>` رابط، `<bN>…</bN>` غامق، `<iN>…</iN>` مائل، `<sN>…</sN>` سائر الوسوم، `<cN/>` شيفرةٌ تبقى كما هي، `<gN/>` صورةٌ أو فاصل سطر. النسخ التي لا تعرفه تتجاهله. |

### أسماء المواقع

| الاسم | الموقع |
|---|---|
| `app` | ‏claude.ai (التطبيق) |
| `support` | ‏support.claude.com (مركز المساعدة) |
| `privacy` | ‏privacy.claude.com (مركز الخصوصية) |
| `docs` | ‏platform.claude.com/docs (وثائق المطوّرين) |

## ما يقبله الاستيراد أيضًا

- **ملف الإصدار 1.0.0** (بلا `domain` ولا `domains`)، أو **مصفوفة مجرّدة** `[{ "en": …, "ar": … }]`، أو **كائن مسطّح** `{ "النص الإنجليزي": "الترجمة" }`: الملف لا يذكر موقعه، فـ**يُسأل عنه** قبل الاستيراد. والاختيار المقترح هو الموقع المختار في رأس الصفحة؛ وفي «المواقع كلها» لا اقتراح، فيُختار الموقع صراحةً. ويسمّي التأكيدُ الموقعَ الذي سيُكتب فيه.
- **ردّ «أمر الترجمة»**: يطلب الأمر من النموذج ردًّا يحمل موقعه (`{"domain": …, "terms": […]}`، أو `{"domains": {…}}` حين نُزّل الأمر من «المواقع كلها»)، فيعود كل قسمٍ إلى موقعه دون سؤال.
- **الملف المنظَّم يُعرف بتوقيعه وأنواع قيمه، لا بأسماء مفاتيحه**: `_app` قيمته `claude-mutarjim`، أو `_kind` نصٌّ، أو `_version` رقم، أو `terms` أو `rules` مصفوفة، أو `blocks` أو `domains` كائن، أو `data.cml_overrides` كائن (النسخة الشاملة من الإصدار 1.0.0). فيه لا تُقرأ التصحيحات إلا من حقولها (`terms` و`rules`، أو `data.cml_overrides`)، ولا يُقرأ موقعه إلا من `domain` و`domains`، **فحقول الرأس لا تُستورد تصحيحاتٍ** أبدًا.
- وما سوى ذلك **كائنٌ مسطّح**: كل قيمةٍ نصّية فيه تصحيح، ويُتجاهل منه كل مفتاحٍ يبدأ بشرطةٍ سفلية. فمفتاحٌ مثل `"terms"` أو `"data"` أو `"domain"` قيمتُه نصٌّ هو نصٌّ من الواجهة يُستورد كغيره («terms» ← «الشروط»)، ولا يجعل الملف منظَّمًا ولا يُقرأ اسمَ موقع.

## ما يجري عند الاستيراد

1. **يُعرض عليك قبل الكتابة** عددُ ما سيُستورد لكل موقع — التصحيحات والقواعد الذكية وتصحيحات الفقرات كلٌّ بعدّه — وأول خمسة تصحيحات وأول ثلاث فقرات منه. الملف يستطيع تغيير نصّ أي زرّ، فلا تستورد إلا من مصدرٍ تثق به.
2. **القسم لموقعٍ لا تعرفه الإضافة يُتجاهل**، ويُذكر اسمه في رسالة التأكيد.
3. **ما يتجاوز الحدود لا يُكتب**: نصٌّ إنجليزي أطول من 300 حرف، أو ترجمةٌ أطول من 600، أو قاعدةٌ ذكية لا يقبلها حارس الأمان (متغيّرٌ في الترجمة ليس في الأصل، أو نصٌّ ثابت أقصر من أن يميّز). وفي `blocks`: مفتاحٌ ليس بصمةً، أو قالبٌ مختلّ الرموز، أو أطول من 8000 حرف. وهذه حدود المحرّك نفسه، فما يتجاوزها لن يُطبَّق على الصفحة أصلًا — وقالبٌ لا تطابق رموزُه فقرتَه في الصفحة تبقى فقرتُه على ترجمة الإضافة.
4. **سقفا الإضافة الجديدة**: 20000 تصحيح و2000 قاعدة ذكية لكل موقع. تحديثُ ما هو موجود لا يُحسب من السقف.
5. **حجم الملف** لا يتجاوز 5 ميغابايت.
6. **ملفٌّ من إصدارٍ أحدث** (`_version` أكبر من 2): يُستورد منه ما تفهمه النسخة المثبّتة، أي التصحيحات والقواعد، ويُترك ما سواه. ورسالة التأكيد تصرّح بذلك.
7. **الاستيراد إضافةٌ لا استبدال**: تصحيحٌ موجود بالنص نفسه تُستبدل ترجمته، وما ليس في الملف يبقى كما هو.
8. **أمرٌ يبدأ ثم يُعاد الضبط من تبويبٍ آخر قبل تأكيده لا يُكتب.** تظهر رسالة، وتعيد المحاولة.

## ما ليس في الملف

إعدادات الإضافة (التفعيل، الاتجاه، المحرّك) ونتائج الفحص والمزامنة ليست في هذا الملف. فيه عملُك وحده: تصحيحاتك وقواعدك الذكية وتصحيحات الفقرات.
